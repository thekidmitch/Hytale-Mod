# Roadmap

The roadmap is exploratory and may change as Hytale APIs and the project evolve.

## Phase 1 — Companion Foundation

- [x] Java plugin foundation.
- [x] Local Ollama integration.
- [x] Erik personality and conversation.
- [x] Persistent memory and relationship data.
- [x] Goal and journal data.
- [x] Initial NPC role definition.
- [x] Successful NPC spawn test.

## Phase 2 — Reliable NPC

- [ ] Prevent duplicate NPC spawning.
- [ ] Improve NPC movement and navigation.
- [ ] Connect AI decisions to in-game actions.
- [ ] Improve persistence and recovery.
- [ ] Test behavior across world sessions.

## Phase 3 — Independent NPCs

- [ ] Individual needs and priorities.
- [ ] Skills, preferences, and values.
- [ ] NPC-to-NPC relationships.
- [ ] Autonomous daily routines.
- [ ] Dynamic goals and task selection.

## Phase 4 — Settlement Simulation

- [ ] Shared settlement resources.
- [ ] Work assignments and professions.
- [ ] Construction and expansion.
- [ ] Trading and cooperation.
- [ ] Leadership, loyalty, disagreement, and conflict.
- [ ] Small-group settlement simulation.

## Phase 5 — Performance and Release

- [ ] Performance testing with multiple NPCs.
- [ ] Configuration and installation documentation.
- [ ] Compatibility testing.
- [ ] Public testing release.
